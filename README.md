3SMB - E-commerce Website

Welcome to 3SMB, a user-friendly e-commerce website for purchasing electronic gadgets. This project provides a complete online shopping experience, from product selection to secure checkout with OTP verification for authentication.

Features

1. User Authentication and Authorization

Sign-Up Page: New users can create an account.

Login Page: Existing users can log in.

OTP Verification: Secure OTP-based authentication for enhanced security.

2. Product Catalog

Browse a wide range of electronic gadgets.

View detailed descriptions and specifications of each product.

3. Shopping Cart

Add desired products to the cart.

Modify quantities or remove items before checkout.

4. Demo Payment Gateway

Simple demo transaction page for payment processing.

Secure and easy-to-use payment flow.

5. Order Management

Review orders after payment.

Email confirmation for successful transactions.
